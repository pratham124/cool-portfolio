# cool-portfolio

Interactive 3D space-themed portfolio built with `three.js` and Vite.

## Concept

- Desktop: steer a rocket through space and dock at planets for `About`, `Skills`, `Projects`, and `Contact`.
- Mobile: keep the same 3D scene, but switch to touch-first planet selection with auto-travel.

## Run

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
